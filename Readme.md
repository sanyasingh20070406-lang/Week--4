# BlogSpace - Mini Blog UI

## About the Project

BlogSpace is a responsive blog frontend developed using HTML,
CSS and JavaScript.

It allows users to explore blog articles, search posts,
filter articles by category and read individual blog details.

## Features

- Responsive homepage
- Blog cards
- Search functionality
- Category filtering
- Individual blog detail pages
- Mock JSON data
- Fetch API integration
- Loading, error and success states

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Fetch API

## Project Structure

Blog-UI/
- index.html
- blog.html
- style.css
- script.js
- blog.js
- blogs.json
- README.md

## How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension.
4. Right-click index.html.
5. Select Open with Live Server.
6. Explore the blog website.

## Learning Outcomes

- Working with JSON data
- Fetching data using JavaScript
- DOM manipulation
- Creating responsive layouts
- Implementing search and filtering
- Handling loading and error states
